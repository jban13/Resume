# Resume
Automatische Erstellung des Lebenslaufs. Daten werden in getrennten yml-Dateien gespeichert

HTML-Datei baut sich selber mit einem Push auf GitHub Pages auf.
Dafür nur die Yaml-Dateien anpassen.

Resume.css beinhaltet die Formatierung für die Website
index.html ist die Übersicht, wo die Daten aus den Yaml-Dateien eingefügt werden soll.
